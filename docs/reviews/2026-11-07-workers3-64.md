# 3–64 下载线程选择复审

- 界面下拉框包含 3–64 全部 62 个整数；旧配置与未设置值默认 16，越界整数限制到边界。
- 选择自动持久化到 `download_workers`；配置克隆、自动保存和立即保存均保留该字段。
- 下载开始时复制线程数，期间禁用选择并防御选择通知，结束后恢复。下载器分段循环和边界计算均使用选定值，固定 4 MiB 并发门槛不随线程数改变。
- 所有 62 个值均验证实际重叠请求数和不等长分段文件拼接；3、17、64 验证更新器完整 ZIP 下载及校验链路。
- 原生 Windows 控件测试验证全部选项、默认值、选择保存和忙碌锁定；极端长度边界、旧配置兼容、配置往返与快照均通过。
- 全量 `go test -race -count=3 -v ./...` 和 `go vet ./...` 通过。独立构建程序启动、正常关闭及默认配置保存通过。
- 末轮复审未发现新增问题。服务器不支持分段或文件过小时仍走单连接；较高线程数不保证更快。
