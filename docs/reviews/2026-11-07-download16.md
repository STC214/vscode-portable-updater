# 16 路下载器复审

## 范围

本次新增的下载器、与原更新流程的连接、回归测试及文档。生产程序保留已有 ZIP CRC、版本、架构与安装事务保护。

## 复审及修复

1. 响应与兼容性：新增测试复现了版本标识未复核、探测响应编码/长度未校验、探测成功后 Range 被忽略时未回退，以及单连接长度不匹配的问题；逐项修复。
2. 并发与边界：新增测试复现从分段回退到单连接时进度从 93% 回退到 6%；修复为单调进度。另检查取消传播、极端长度的整数溢出、弱 ETag 与 Last-Modified 的强校验条件。
3. 超时与收尾：固定 2 分钟的分段总时限会让共享低带宽连接反复重下，调整为无数据超时，保留整个下载的 30 分钟上限；测试持续低速与停滞两种行为。文件关闭成功后才报告 100%，重试日志记录实际尝试次数。检查失败临时文件清理与旧缓存保留。

## 验证

- `go test -race -count=3 ./...`：全量回归与数据竞争检测。
- `go vet ./...`：静态检查。
- `go test -run '^$' -fuzz '^FuzzDownloadContentRange$' -fuzztime=20s -parallel=4 .`：范围解析及边界模糊测试，269,045 次执行通过。
- 本地 HTTP 服务通过屏障验证 16 个分段请求实际重叠，校验完整输出内容；涵盖重试、回退、响应变化、截断与未知长度场景。
- 显式网络测试下载官方 ZIP 并执行 CRC、版本及架构校验，不执行安装。发布验证记录另存于构建产物目录。

末轮复审与上述测试未发现新的问题；这不是对所有网络、磁盘和运行环境均无缺陷的保证。跨次启动续传仍未实现。
