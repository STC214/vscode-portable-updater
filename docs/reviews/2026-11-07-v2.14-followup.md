# V2.14 后续复审

## 复现并修复

1. 打开线程列表后预览到 64，尚未确认，内存和磁盘就变成 64。改为区分预览与确认，路径同步不再读取未确认值。
2. 原生 Esc 通知后 Windows 仍会改写控件选择；立即恢复不足以保持界面一致。进一步验证通知顺序存在差异，现通过 UI 队列在本轮原生通知结束后统一对齐已提交值，兼容确认、取消及关闭通知的先后变化。
3. 窗口缩小时路径视口被强行按至少 80 像素计算，导致滚动范围偏小，路径行还会越界遮挡日志。改为实际可用高度、隐藏越界行，并修复 Win32 滚动条最大值的包含端点及零视口边界。
4. 静态检查发现新增选项文字转换为 uintptr 后跨包装函数传递，补充 KeepAlive 保证原生复制完成前仍存活；此项为生命周期加固，未宣称已复现文字损坏。

## 验证

- 隐藏的原生测试窗口发出真实方向键、Enter、Esc，接收真实 WM_COMMAND 通知并处理 UI 队列。
- 五种确认/取消/关闭通知顺序，闭合列表的键盘修改、预览中启动更新、后续路径保存均有回归覆盖。
- 200、360、400、480、760 高度下验证路径视口、滚动边界和顶/中/底位置，检查可见路径行不会遮挡进度或日志。
- 全部 3–64 线程的并发、持久化和 ZIP 校验旧测试继续运行；全量竞态检查和高频 GC 压力测试结果保存在发布验证目录。
- 末轮复审未发现新增问题；不等同于对所有运行环境的绝对无缺陷保证。
